# The Cube Vault — Cube Adventure legacy builds

Old builds of **Cube Adventure — The Lost Shards**, kept for preservation.
Download them from the [Releases](../../releases/tag/vault-1) page or from
[eithancrea.pages.dev/legacy](https://eithancrea.pages.dev/legacy).

These builds are English only, Windows only and have no online features.
For the real adventure, play the latest version on
[itch.io](https://eithancrea.itch.io/cube-adventure).
